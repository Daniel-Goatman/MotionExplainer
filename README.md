# MotionExplainer

Agent-led video explainers built with [Remotion](https://www.remotion.dev). You bring source material; an AI coding agent turns it into a narrated, storyboard-first explainer video with continuous motion and a consistent design system.

> **Speech runtime: set this up yourself.** Narration is generated by a swappable speech layer in `speech/`. The default provider is local **Kokoro** (`kokoro-mlx`, Apple silicon), which most machines will not have installed. You can install Kokoro, point the `command` provider at any text-to-speech CLI you already use, or copy `speech/providers/template.py` to connect a hosted service such as ElevenLabs or OpenAI. No hosted service is wired in, and no API keys are needed to use the rest of the repo.

> **Recommended agent: Claude.** Use Claude (for example Claude Code) for video generation. In our use, Codex produces noticeably weaker storyboards, motion and visual judgement.

## How it works

1. **Brief.** Create `jobs/<job-id>/` with a README: audience, sources, what must be accurate, what is illustrative.
2. **Plan.** The agent outlines chapters and maps claims to sources.
3. **References and storyboards.** One drawn reference frame per chapter, then real storyboards: key states, narration, emphasis cues and the continuous transition between states. You review and approve.
4. **Narrated sample.** One representative passage is built with real narration and motion. You review it.
5. **Production.** Narration for every sentence, cue timing measured from the audio, all scenes built, rendered, and checked (frames, transitions, sync, loudness).
6. **Delivery.** MP4 with chapter markers, captions, transcript, sources and credits in `jobs/<job-id>/out/`.

The creative rules live in `VIDEO-GENERATION.md` (process), `DESIGN.md` (visual system, tokens in `src/design/tokens.ts`) and `PIPELINE.md` (commands). Agents load them through `skills/video-explainer/SKILL.md`, linked into `.claude/skills` and `.agents/skills`.

## Install

Requirements: Node.js 20+, [pnpm](https://pnpm.io), Python 3.10+, ffmpeg.

```bash
git clone https://github.com/<you>/MotionExplainer.git
```

```bash
cd MotionExplainer && pnpm install --frozen-lockfile
```

Then set up a speech provider (one of):

```bash
pip install kokoro-mlx
```

```bash
export SPEECH_PROVIDER=command SPEECH_COMMAND='say -v Samantha -f {text_file} -o {out}.aiff'
```

Check everything works:

```bash
node scripts/video-job.mjs <job-id> compositions
```

The workspace uses the system font stack (SF on macOS). Fonts are not bundled.

## Speech providers

| Provider | Use | Setup |
|---|---|---|
| `kokoro` | Local neural voice (default) | `pip install kokoro-mlx`; optional `KOKORO_MODEL` (local dir or Hugging Face id) |
| `command` | Any local TTS command line (macOS `say`, Piper, ...) | `SPEECH_COMMAND` template with `{text_file}`, `{out}`, `{voice}`, `{speed}` |
| your own | A hosted service | Copy `speech/providers/template.py`, implement `synthesize`, register it in `speech/providers/__init__.py` |

```bash
python3 -m speech.synthesize jobs/<job-id>/audio/segments.json jobs/<job-id>/public/audio/narration --provider kokoro --voice bm_daniel
```

```bash
python3 -m speech.measure jobs/<job-id>/audio/segments.json jobs/<job-id>/public/audio/narration jobs/<job-id>/src/timing.json
```

Scenes only read the WAV files and the timing JSON, so switching provider never changes scene code.

## Agent setup instructions

Paste this into your agent after cloning:

```text
Set up this MotionExplainer repository for me.
1. Read README.md, AGENTS.md, VIDEO-GENERATION.md, DESIGN.md, PIPELINE.md and skills/video-explainer/SKILL.md.
2. Check Node.js 20+, pnpm, Python 3.10+ and ffmpeg are available; tell me what is missing rather than installing system software silently.
3. Run `pnpm install --frozen-lockfile`. Do not add or upgrade packages.
4. Ask me which speech provider to use (kokoro, command, or a hosted service I will wire in myself). Configure it, then generate one test sentence with `python3 -m speech.synthesize` into a scratch folder and confirm a WAV was produced.
5. Create jobs/example/ with a short README brief, an index.ts that registers a one-composition Root, and render one still with `node scripts/video-job.mjs example still <CompositionId> check.png --frame=0` to prove the toolchain.
6. Report what works and what still needs my input. For real videos, follow the storyboard → approval → narrated sample → production process in VIDEO-GENERATION.md and stop at each review checkpoint.
```

## Layout

```
AGENTS.md, CLAUDE.md     agent rules (shared by any agent)
VIDEO-GENERATION.md      creative process and review gates
DESIGN.md, design-source/, src/design/   visual system and tokens
PIPELINE.md, scripts/    job runner and maturity check
speech/                  swappable narration layer
skills/video-explainer/  the shared agent skill
jobs/                    one folder per video (git-ignored)
```
