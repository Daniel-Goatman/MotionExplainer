Use ReturnLink as the quiet way back from a drill-in: a chevron and the name of the place you return to ("Whole disk", "All places").

**Provide:** `label` and `onClick`.

**Controller:** `show(on)`. It slides in only while there is somewhere to go back to.

**Also:** wire Esc to the same action.

**Don't** use underlined or tab-style buttons, a generic bottom button bar, or the word "Back" alone when a place name is clearer.
